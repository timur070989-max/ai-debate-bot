# 🤖 Multi-Agent AI Debate Telegram Bot

Два AI-агента обсуждают твои задания и вместе находят лучшее решение!

## 🏗️ Архитектура

- **🟣 Agent Alpha** — Groq (Llama 3.3 70B) — быстрый практик
- **🔵 Agent Beta** — Google Gemini Flash — аналитик-архитектор
- **👤 Ты** — даёшь задания и можешь вмешаться в любой момент

## ⚡ Быстрый старт

### 1. Получи API ключи (бесплатно)

| Сервис | Где получить |
|--------|-------------|
| Telegram Bot | [@BotFather](https://t.me/BotFather) → /newbot |
| Groq API | [console.groq.com](https://console.groq.com) → API Keys |
| Google Gemini | [aistudio.google.com](https://aistudio.google.com) → Get API Key |

### 2. Настрой проект

```bash
# Установи зависимости
pip install -r requirements.txt

# Создай файл .env
copy .env.example .env

# Заполни ключи в .env
notepad .env
```

### 3. Запусти бота

```bash
python bot.py
```

### 4. Открой Telegram

1. Найди своего бота по имени
2. Нажми `/start`
3. Отправь задание: `/task Напиши функцию сортировки на Python`
4. Наблюдай за дебатами! 🍿

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие |
| `/task <текст>` | Новое задание |
| `/stop` | Остановить обсуждение |
| `/history` | История |
| `/rounds <N>` | Макс. раундов (1-20) |
| `/status` | Текущий статус |

## 💡 Фишки

- **Вмешательство**: Просто напиши сообщение во время обсуждения — агенты учтут его
- **Авто-согласие**: Агенты сами определяют, когда пришли к единому мнению
- **Разные мнения**: У агентов разные «характеры» — один практик, другой аналитик
